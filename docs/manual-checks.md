# Revit 2026 수동 확인 절차

아래 항목은 실제 Revit에서 확인할 절차입니다. 아직 실행 완료로 기록하지 않았습니다.

1. Revit 2026을 지원하는 pyRevit을 설치·연결합니다. `scripts/install-extension.ps1`로 확장을 설치하고 Revit을 재시작합니다. `RevitAuto → 도면 자동화`의 아이콘과 버튼 3개를 확인합니다.
2. 도곽을 로드하고 `samples/house-sheets.csv`를 가져옵니다. 미리보기에 시트 5개가 보이고 취소하면 시트가 생기지 않는지 확인합니다.
3. 생성 후 번호·이름·도곽을 확인합니다. 실행 취소 1회로 시트 5개가 모두 사라지는지 확인합니다.
4. 다시 생성한 뒤 같은 CSV를 가져옵니다. 중복 메시지가 나오고 기존 시트 개수와 내용이 바뀌지 않아야 합니다.
5. 기존 시트와 충돌하는 번호, 빈 이름, 중복 번호, 잘못된 따옴표가 있는 CSV를 각각 가져옵니다. 어떠한 시트도 생성하지 않아야 합니다.
6. 뷰 선택 창에서 미배치 평면·입면·단면 뷰를 여러 개 체크하고 미리보기를 확인해 자동 배치합니다. 선택한 뷰마다 RA 번호의 새 시트와 뷰포트가 하나씩 생성되는지 확인합니다. 도곽이 있는 경우와 없는 경우를 모두 확인합니다.
7. 기존 `RA-001`, `RA-003` 시트가 있을 때 새 번호가 충돌하지 않는지 확인합니다. 기존 시트에 배치된 뷰와 뷰 템플릿은 선택 목록에서 제외되어야 합니다.
8. 뷰 배치 직후 실행 취소합니다. 새 시트와 뷰포트가 모두 사라지고 원래 뷰는 남아 있어야 합니다.
9. 변경 권한이 없는 모델·소유권 충돌 등으로 명령이 실패할 때 일부 시트만 남지 않는지 확인합니다.
10. 시트·뷰 상세정보를 ZIP으로 저장하고 CSV와 JSON의 한글·쉼표·따옴표를 확인합니다. `placements`와 `view_elements`의 키로 시트→뷰→요소 관계를 추적하고, 원시 값·표시 값·단위가 실제 속성 창과 같은지 확인합니다.
11. 프로젝트를 닫거나 패밀리 문서를 열었을 때 버튼 비활성화를 확인합니다.
12. 큰 뷰와 3D 뷰의 축척·도곽 여백·제목 위치를 확인하고 출력 전 조정합니다. 중앙 배치만 자동화하며 용지에 맞춤은 지원하지 않습니다.
13. 한글 번호·이름이 있는 CSV를 가져와 미리보기와 생성된 시트 이름이 원문과 같은지 확인합니다. 상세정보를 다시 내보내 Excel과 메모장에서 한글을 확인합니다.
14. 기본 `{3D}` 뷰를 자동 배치하면 새 시트 이름은 `3D`로 생성되고, 원래 뷰 이름은 `{3D}`로 유지되는지 확인합니다. CSV에 금지 문자를 직접 입력한 경우에는 시트 생성 전에 이름 오류가 표시되어야 합니다.
15. 이름 한 열 CSV를 헤더가 있을 때와 없을 때 각각 가져옵니다. `A-001`, `A-003`이 이미 있으면 `A-002`, `A-004`처럼 충돌을 피하는지 확인합니다.
16. 상세정보에서 도곽 사용자 파라미터, 개정 정보, 문자·태그·치수, 일람표 셀, 유형 파라미터와 재료가 실제 모델과 같은지 확인합니다.
17. 직접 로드된 링크가 있는 뷰를 선택해 링크 인스턴스 변환과 링크 요소의 키를 확인합니다. 링크가 로드되지 않았으면 누락 사유가 `issues.csv`에 나타나야 합니다.
18. PDF 포함으로 내보낸 ZIP에서 `sheets.pdf`가 열리는지 확인합니다. PDF 출력 실패 시 CSV·JSON은 남고 완료 메시지·`manifest.json`·`issues.csv`에 실패가 표시되어야 합니다.
19. 수집 중 취소 시 새 ZIP이 생기지 않고 모델이 바뀌지 않는지 확인합니다. 이미 있는 ZIP을 덮어쓸 때 쓰기 실패가 나면 기존 파일이 보존되는지도 확인합니다.
