# 기존 도면으로 처음 실습하기

RVT 모델을 복사해서 실습합니다. PDF·DWG 도면만으로는 Revit API 시트 자동화를 실행할 수 없습니다. 코드 실행에는 Revit과 pyRevit이 필요합니다.

## 1. 실습용 파일 열기

현재 작업을 저장한 뒤 Revit을 재시작해 `RevitAuto → 도면 자동화` 리본이 보이는지 확인합니다. 원본 모델을 복사한 `house-practice.rvt`를 열고, 이후 실습 결과는 이 사본에 저장합니다. 로컬 `.local/practice/` 폴더는 Git에서 제외되며 모델은 저장소에 올리지 않습니다.

## 2. 시트 목록부터 저장하기

‘시트 목록 내보내기’를 누르고 `before.csv`로 저장합니다. 모델에 손대지 않고 기존 시트 번호와 이름을 확인할 수 있습니다.

## 3. 실습 시트 3개 만들기

‘CSV 시트 일괄 생성’에서 [practice-sheets.csv](../samples/practice-sheets.csv)를 선택합니다.

```csv
Number,Name
PRACTICE-001,실습 - 1층 평면도
PRACTICE-002,실습 - 2층 평면도
PRACTICE-003,실습 - 입면도
```

도곽을 고르고 미리보기에서 번호·이름을 확인해 생성합니다. 기존 `A101` 등의 도면 번호를 피하려고 실습용 접두사를 붙였습니다. 같은 실습 번호가 이미 있다면 CSV 번호를 바꾸세요.

프로젝트 탐색기의 시트 목록에 3개가 추가되면 성공입니다. 이 단계는 **빈 시트 생성**이며 벽이나 기존 도면을 새로 그리거나 바꾸지 않습니다. 실행 취소 1회로 세 시트를 함께 되돌릴 수 있습니다.

## 4. 뷰 자동 배치해 보기

‘뷰 → 시트 자동 배치’를 누르고 아직 시트에 배치하지 않은 뷰 한 개만 선택해 시작합니다. 도곽과 미리보기를 확인하면 `RA-001` 같은 새 시트에 뷰가 배치됩니다.

이 버튼은 앞에서 만든 `PRACTICE` 시트를 채우는 기능이 아닙니다. **뷰마다 별도 새 시트를 생성**합니다. 현재 모델의 뷰가 모두 기존 시트에 올라가 있다면, Revit에서 뷰 하나를 ‘상세 포함 복제’한 후 실습용 이름을 붙이고 그 뷰를 선택하세요. 축척 자동 맞춤은 없으므로 큰 뷰의 용지 여백은 직접 확인합니다.

## 5. 결과 비교하기

시트 목록을 `after.csv`로 다시 내보내고 `before.csv`와 비교합니다. 실습 시트와 자동 배치 시트가 추가됐는지, 기존 번호와 이름이 그대로인지 확인합니다. 결과가 마음에 들면 사본만 저장하고, 다시 시작하려면 사본을 닫고 원본에서 새 사본을 만듭니다.

문제가 생기면 오류 창의 메시지와 사용한 CSV를 확인합니다. 실제 Revit에서 결과를 확인하기 전까지는 자동 검사 통과와 실제 모델 적용 성공을 구분합니다.
